# 🃏 Poker Planning Application

Приложение для покер-планирования (Planning Poker) с использованием React, TypeScript, MobX и Ant Design.

## 📋 Возможности

- ✅ Создание комнат для планирования
- ✅ Добавление задач для оценки
- ✅ Вход как Owner (с паролем) или как Участник
- ✅ Голосование по шкале Фибоначчи: 0, 1, 2, 3, 5, 8, 13, 21, 34, 55, ?
- ✅ До 10 участников в комнате
- ✅ Отображение результатов голосования
- ✅ История голосований
- ✅ Сохранение данных в localStorage

## 🚀 Установка и запуск

### Требования
- Node.js 25.8.0 или выше
- npm 11.11.0 или выше

### Установка зависимостей
```bash
npm install
```

### Запуск приложения
```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173/

## 📖 Как использовать

### Для Owner (Создатель комнаты)

1. **Создание комнаты**
   - Откройте главную страницу
   - Введите название комнаты
   - Введите ваше имя
   - Придумайте пароль (необходим для повторного входа)
   - Добавьте задачи для оценки (название + описание опционально)
   - Нажмите "Создать комнату"

2. **Запуск голосования**
   - В комнате вы увидите список задач
   - Нажмите "Запустить голосование" рядом с задачей
   - Дождитесь, пока все участники проголосуют
   - Когда все проголосуют, нажмите "Раскрыть карты"
   - Система покажет результаты и рассчитает итоговую оценку

3. **Просмотр результатов**
   - Итоговая оценка рассчитывается как среднее арифметическое
   - Среднее значение округляется до ближайшего числа Фибоначчи
   - История голосований сохраняется и доступна внизу страницы

### Для Участника

1. **Вход в комнату**
   - Перейдите по ссылке, которую предоставил Owner
   - Выберите роль "Участник"
   - Введите ваше имя
   - Нажмите "Войти как участник"

2. **Голосование**
   - Дождитесь, когда Owner запустит голосование
   - Выберите оценку из шкалы Фибоначчи
   - Нажмите на карточку с числом
   - Ваш голос будет зафиксирован
   - Дождитесь, когда Owner раскроет карты

3. **Просмотр результатов**
   - После раскрытия карт вы увидите оценки всех участников
   - Итоговая оценка будет показана prominently

## 🎯 Шкала оценок

Приложение использует стандартную шкалу Фибоначчи для планирования:
- **0** - Задача тривиальная или уже выполнена
- **1** - Очень маленькая задача
- **2** - Небольшая задача
- **3** - Средняя задача
- **5** - Большая задача
- **8** - Очень большая задача
- **13** - Огромная задача
- **21, 34, 55** - Эпические задачи (требуют декомпозиции)
- **?** - Не могу оценить (нужно больше информации)

## 🔒 Безопасность

⚠️ **Важно:** Это демонстрационная версия приложения.
- Пароли хранятся в plaintext в localStorage
- Нет серверной валидации
- Нет WebSocket синхронизации между участниками
- Все данные хранятся локально в браузере

Для продакшн-использования необходимо:
- Добавить WebSocket/сервер для синхронизации в реальном времени
- Хэшировать пароли
- Добавить серверную валидацию
- Реализовать систему авторизации
