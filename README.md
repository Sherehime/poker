# 🎲 Покер-планирование

Приложение для покер-планирования с использованием WebSocket, React и MobX.

## 🚀 Возможности

- ✅ Создание комнат для планирования
- ✅ Присоединение участников по ссылке
- ✅ Роль Owner (создатель комнаты) и Voter (участник)
- ✅ Голосование по шкале Фибоначчи (0, 1, 2, 3, 5, 8, 13, 21, 34, 55, ?)
- ✅ Реальное время через WebSocket
- ✅ История голосований
- ✅ До 10 участников в комнате

## 🛠️ Технологии

### Frontend
- **React 19.2** - UI библиотека
- **MobX 6.15** - управление состоянием
- **Ant Design 6.3** - UI компоненты
- **Socket.io-client 4.7** - WebSocket клиент
- **React Router 7.13** - маршрутизация
- **Vite 7.3** - сборщик

### Backend
- **Node.js 25.8** - runtime
- **Express 4.18** - HTTP сервер
- **Socket.io 4.7** - WebSocket сервер
- **SQL.js 1.10** - база данных SQLite
- **TypeScript 5.9** - типизация

## 🎮 Как пользоваться

### 1. Создание комнаты (Owner)

1. Откройте http://localhost:5173
2. Нажмите "Создать новую комнату"
3. Заполните:
   - Название комнаты
   - Ваше имя
   - Пароль (запомните его!)
   - Добавьте задачи для оценки
4. Нажмите "Создать комнату"
5. Скопируйте ссылку-приглашение и поделитесь с командой

### 2. Присоединение к комнате (Участник)

1. Перейдите по ссылке-приглашению от Owner
2. Выберите роль "Участник"
3. Введите ваше имя
4. Нажмите "Войти как участник"

### 3. Проведение голосования

**Owner:**
1. В комнате выберите задачу из списка
2. Нажмите "Запустить голосование"
3. Дождитесь, пока все участники проголосуют
4. Когда все проголосовали, нажмите "Раскрыть карты"
5. Результаты будут видны всем участникам

**Участник:**
1. Дождитесь запуска голосования Owner
2. Выберите значение Фибоначчи
3. Дождитесь revelations результатов

### 4. Повторный вход как Owner

1. Введите ID комнаты
2. Выберите роль "Owner"
3. Введите ваш пароль
4. Нажмите "Войти как Owner"

## 📁 Структура проекта

```
poker/
├── src/                    # Frontend
│   ├── components/         # React компоненты
│   │   ├── CreateRoom.tsx  # Создание комнаты
│   │   ├── JoinRoom.tsx    # Вход в комнату
│   │   ├── Room.tsx        # Комната планирования
│   │   ├── VotingCards.tsx # Карточки для голосования
│   │   ├── VotingResults.tsx # Результаты
│   │   ├── History.tsx     # История голосований
│   │   └── Home.tsx        # Главная страница
│   ├── stores/             # MobX сторы
│   │   └── RoomStore.ts    # Store комнаты
│   ├── services/           # Сервисы
│   │   └── socket.ts       # Socket.io клиент
│   ├── types/              # TypeScript типы
│   └── App.tsx             # Главный компонент
├── server/                 # Backend
│   ├── index.ts            # Точка входа
│   ├── db.ts               # База данных
│   ├── handlers/           # Обработчики WebSocket
│   │   ├── room.handler.ts # Комнаты
│   │   ├── voting.handler.ts # Голосования
│   │   └── index.ts        # Экспорт обработчиков
│   └── types.ts            # Типы сервера
└── poker.db                # SQLite база данных (создаётся автоматически)
```

## 🔐 Безопасность

- Пароль Owner хешируется перед сохранением
- Валидация всех входных данных
- Проверка прав доступа

## 🐛 Известные проблемы

- База данных хранится в файле (для production рекомендуется использовать PostgreSQL)
- Нет автоматической очистки старых комнат
